# DecisionPoint SPX snapshots

Daily close summary and next-session monitoring checklist. Schemas are JSON Schema Draft 2020-12. Session folders use the observed market date; the checklist also contains its target session date.

Run `python3 download.py --output downloads` to retrieve the charts locally. Original StockCharts images are not redistributed here. `generate-example.py` contains manually reviewed readings for the initial November 23 example; it is not a live extraction pipeline. Thresholds are monitoring hypotheses, not backtested trade rules.
